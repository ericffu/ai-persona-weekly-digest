# 行业配置记录

"XX 行业从业者"角色每跑一次,把该行业的专项搜索关键词与关注公司/机构名单记录在这里,下次同一行业直接复用,不用从零现想关键词、不用重新问一遍关注哪些公司。

## 使用规则

- **生成前**:按行业名(取用户说法的常见简称,如"教育"而不是"K12 教育培训行业")查下面有没有对应的 `## <行业>` 小节
  - **有** → 直接复用该节的「专项搜索关键词」发起本轮搜索,「关注公司/机构名单」直接采用,不用重新问用户,除非用户这次主动提到要加/删公司
  - **没有** → 说明是第一次遇到这个行业,按 SKILL.md「行业专项搜索」的通用模式现想关键词,正常追问关注公司名单
- **生成后**:
  - 第一次遇到的行业 → 在本文件末尾新建一节,记录本轮实际用的关键词(中英各一份)、用户给的公司名单、首次记录日期
  - 已有记录的行业 → 如果这轮搜索又发现了明显更好用的新关键词,或用户调整了关注公司名单,回来**追加/修订**对应字段,不要整节重写、不要删掉旧关键词(除非确认它已经搜不出东西了)
- 一个行业只保留一节,不要重复建节;行业名如果用户几次说法不同(比如"教育"和"K12"),视为同一个,合并到一节里,备注里注明别名

## 记录格式

```markdown
## <行业名>

- **首次记录**:<YYYY-MM-DD>
- **最近更新**:<YYYY-MM-DD>
- **专项搜索关键词**:
  - 中文:`关键词1`、`关键词2`、…
  - 英文:`keyword1`、`keyword2`、…
- **关注公司/机构名单**:<公司 A>、<公司 B>、…(没有就写"暂无")
- **备注**:别名、行业特有的判断逻辑、踩过的坑等,可选
```
